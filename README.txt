MANY THREADS: multi-page website  (live address: https://manythreads.netlify.app)
Put it online: drag this whole folder onto https://app.netlify.com/drop, then set the site name to "manythreads" in Site configuration > Change site name.
SEO is already set for that address: canonical links, Open Graph / Twitter cards, structured data, sitemap.xml, robots.txt, 404 page.
If the final address is different, search-and-replace https://manythreads.netlify.app in all .html files, sitemap.xml and robots.txt.
Edit assets/site.js ("EDIT THESE" block near the top): wa (WhatsApp number, digits only with country code), pay (optional payment link), email, SOC (social links).
Replace photos by overwriting files in assets/img (keep the same names).
After going live, submit https://manythreads.netlify.app/sitemap.xml in Google Search Console.
